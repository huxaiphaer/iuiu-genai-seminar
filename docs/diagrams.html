Overview

What we are building

A student asks a question. The assistant decides what kind of question it is, finds the answer in approved documents or a safe tool, asks a human when the question is sensitive, and replies with its source.

Day 1 · LangChain

A straight line

In LangChain we wire steps with the pipe |. The Day 1 assistant treats every question the same way: retrieve, then answer.

Day 2 · LangGraph

A graph that decides

LangGraph builds the app from state (shared data), nodes (steps) and edges (arrows). Now a router sends each question down a different path, and sensitive ones pause for a human.

Try one question of each kind: What are the library hours? (knowledge), What is 15 * 4? (math), I think my grade is wrong (sensitive → human review).

The one idea

Chain vs Graph, side by side

A chain does the same steps every time. A graph looks at the question and chooses a path — including stopping to ask a human. Start with a chain; reach for a graph when you need decisions, tools, retries and review.
